Connecte votre boutique WooCommerce a PrepareOS.

== Description ==

PrepareOS Sync permet de relier votre boutique WooCommerce a votre compte PrepareOS.

Fonctionnalites :
* Connexion securisee via cle API
* Verification de la connexion en un clic

== Installation ==

1. Telechargez le plugin et placez le dossier `prepareos-sync` dans `wp-content/plugins/`.
2. Activez le plugin depuis le menu "Extensions" de WordPress.
3. Rendez-vous dans WooCommerce > PrepareOS Sync.
4. Collez votre URL PrepareOS et votre cle API.
5. Cliquez sur "Tester la connexion" pour verifier.
